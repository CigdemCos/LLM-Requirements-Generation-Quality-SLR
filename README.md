# Replication Package

This repository contains the replication package for the paper **"A Systematic Literature Review of LLMs for Requirements Generation and Quality Assessment."**

The study analyzes 30 primary studies published in 2025–2026 and retrieved from IEEE Xplore.

## Contents

- **SLR.xlsx:** General information about the selected primary studies, study selection, and extracted data.
- **RQ1.xlsx:** Requirement quality characteristics, positive and negative impacts of LLM-based requirements generation, contributing factors, root causes, limitations, proposed solutions, and mappings to established standards and frameworks.
- **RQ2.xlsx:** Prompting techniques, architectural approaches, workflow strategies, and input artifacts used for LLM-based requirements generation.
- **RQ3.xlsx:** LLM-based requirements quality detection and assessment methods, quality criteria, evaluation approaches, and validation results.

## Purpose

This replication package provides the supporting data for the systematic literature review and enables researchers to examine the data extraction and analysis results presented in the paper.
